# فيلم إحياء الشعر العربي باستخدام Remotion

10 مشاهد و84 لقطة، 1920×1080، 30 إطارًا/ثانية، بدون صوت أو ترجمة الحوار.

أول 6 لقطات من Higgsfield. اللقطات المتبقية تستخدم الرسوم البرمجية الأصلية للمشروع: بيئات 3D وشخصيات مبسطة، وصور مرجعية متحركة في لقطات الحوار. ليست 78 لقطة مولدة بجودة Higgsfield. يمكن استبدال أي لقطة بفيديو Grok في `project/public/shots/` وربطها في `project/src/data/assets.ts`.

## الإخراج على GitHub
بعد ضبط مصادر الوسائط بشكل خاص في Actions secrets وتشغيله يدويًا، يبدأ workflow **Ihyaa film - silent Remotion render**. يرندر المشاهد منفصلة ثم يجمعها، ويتحقق من الدقة وغياب الصوت. بعد نجاح جميع الوظائف يظهر artifact باسم `ihyaa-film-silent-fullhd`. لا يعني وجود ملفات workflow أن الفيديو قد اكتمل؛ راجع حالة Actions.

## تشغيل محلي
```bash
python3 ihyaa-film/prepare.py
cd ihyaa-film/project
npm ci
npm run typecheck
npx remotion render Film out/ihyaa-film-silent-fullhd.mp4 --props=silent-props.json --muted --gl=swangle --codec=h264
```

الإعداد يحمّل الملف الأصلي والأصول الست المعتمدة، ويتحقق من بصمة الملف الأصلي قبل فكّه. النصوص التعليمية الأصلية لا تتغير. يبقى وسم المشاهد المتخيلة وبطاقات العناوين والرسوم التعليمية. أضف الفويس أوفر بنفسك بعد تنزيل الفيديو.

## إعداد المصادر الخاصة
لا توجد روابط الوسائط داخل المستودع. يحتاج التشغيل إلى `IHYAA_SOURCE_URL` لرابط أرشيف المصدر و`IHYAA_MEDIA_URLS` لكائن JSON يربط المعرفات 1-0 إلى 1-5 بروابط المقاطع، محفوظين في GitHub Actions secrets. لا ترسل مفاتيح حسابات أو كلمات مرور. الإعداد الحالي كود جاهز، ولم يُشغَّل تصيير كامل بعد.
